主题：咨询面向赴日自驾游客的网站能否使用少量车型燃油信息

丰田相关负责人：

您好，我正在开发 Fuel Me Japan（https://fuel-me-japan.com/），希望帮助赴日自驾旅行的外国游客寻找加油站，并正确理解日本的燃油标识。网站目前提供手动选择显示油种的功能，尚未公开已核验的车型用油数据库。

我们计划在商业网站中提供一个小规模车型用油核对功能。希望人工查阅贵公司的日本市场车型官方目录和使用手册，只把车型、配置／完整型号、适用范围和使用燃油等事实，用我们自己的文字与油种分类整理。每条记录会标注官方来源链接、适用范围和核查日期。不会复制或重新发布目录图片、表格截图、PDF 文件或整段说明，也不计划自动批量抓取。

初期审查候选是 Yaris G 的汽油 1.5L／CVT／2WD（5BA-MXPA10-AHXGB）和混合动力 1.5L／2WD（6AA-MXPH14-AHXGB），参考贵公司存档目录的主要规格表（内容截至 2025 年 11 月，第 55 页）。这些只是待审候选，尚未加入网站。

为了确认正确的使用方式，想请教：

1. 上述少量事实的整理与商用网站展示是否允许？是否需要单独许可，有没有指定的申请窗口或流程？
2. 我们的网站采用静态文件结构，结构化记录会作为可下载的 JSON 发布，也可能包含在公开 GitHub 仓库中。这样的分发方式是否允许？是否应限制为网站显示或采用其他方式？
3. 若允许使用，需要遵守哪些来源署名、链接、更新、适用范围或其他条件？
4. 为避免把初次登记年月误当成生产年月，核对具体日本租赁车辆的燃油时，应使用哪些可由租车公司提供的车辆信息，才能可靠地对应贵公司的目录／使用手册版本？完整型号是否足够，还是还需其他非个人识别信息？

网站会明确提醒使用者：加油前核对租车文件和油箱盖标识；任何资料不一致或无法确认时，先询问租车公司，不根据相似车型推测用油。我们不会以网站结果替代现场确认，也不会暗示与贵公司有合作或得到贵公司认证。

如本咨询不属于此窗口的受理范围，烦请告知适合的部门或申请渠道。感谢您的帮助。

Fuel Me Japan 运营者

件名：訪日ドライブ旅行者向けサイトでの車種別燃料情報の利用について

トヨタ自動車株式会社
ご担当者様

突然のご連絡失礼いたします。
私は、訪日外国人のドライブ旅行を支援するウェブサイト「Fuel Me Japan」（https://fuel-me-japan.com/）を開発しております。日本でガソリンスタンドを探し、燃料の表示を正しく理解するためのサービスです。現在は利用者が表示する燃料の種類を手動で選択する機能を提供しており、確認済みの車種別燃料データベースはまだ公開しておりません。

今後、商用サイトの機能として、対象を限定した車種別燃料情報の確認機能を検討しております。貴社が公開されている日本国内仕様車の公式カタログおよび取扱説明書を人の目で確認し、車名、仕様・詳細な車両型式、適用範囲、使用燃料といった事実情報のみを、当方の表現と分類で整理したいと考えております。各記録には、公式資料へのリンク、適用範囲、確認日を記載する想定です。カタログの画像、表の画像、PDF ファイル、説明文のまとまった転載・再配布や、自動的な一括収集は予定しておりません。

初期の検討対象は、ヤリス G のガソリン 1.5L・CVT・2WD（5BA-MXPA10-AHXGB）とハイブリッド 1.5L・2WD（6AA-MXPH14-AHXGB）です。貴社公開の過去カタログの主要諸元表（2025 年 11 月現在の内容、55 ページ）を参照しております。いずれも検討段階であり、サイトには掲載しておりません。

適切な利用方法を確認するため、以下についてご教示いただけますでしょうか。

1. 上記のように限定した事実情報を整理し、商用サイトで表示することは可能でしょうか。個別の許諾が必要な場合、申請窓口や手続きをご案内いただけますでしょうか。
2. 当サイトは静的ファイルで構成されており、整理したデータは利用者が取得できる JSON ファイルとして配信され、公開 GitHub リポジトリにも含まれる可能性があります。このような配布方法は可能でしょうか。サイト内の表示に限定するなど、別の方法が必要でしょうか。
3. 利用可能な場合、出典表記、リンク、情報更新、適用範囲などについて、守るべき条件をお知らせいただけますでしょうか。
4. 初度登録年月と生産年月を混同しないため、日本国内で貸し渡される個々のレンタカーの使用燃料を確認する際、レンタカー会社が提供できるどの車両情報を用いれば、該当するカタログ・取扱説明書の版と確実に照合できますでしょうか。詳細な車両型式のみで足りるのか、ほかに個人を特定しない情報が必要なのか、ご案内いただけますと幸いです。

サイトでは、給油前にレンタカーの書類と給油口の表示を確認し、情報が一致しない場合や確認できない場合は、給油前にレンタカー会社へ問い合わせるよう明示する予定です。似た車種から燃料を推測することや、当サイトの情報を現車確認の代わりにすることはせず、貴社との提携・認定を示唆する表現もいたしません。

本件がこちらの窓口のご担当外である場合は、適切なご担当部署または申請先をご案内いただけますと幸いです。
お忙しいところ恐れ入りますが、どうぞよろしくお願いいたします。

# 浏览器与移动布局验收报告

日期：2026-09-30。范围：手动选油、油种多选、地图、筛选、列表／收藏、加油指引和还车流程。

## 测试环境及实际范围

- 标准全套：Node 24.18.0，Playwright Chromium，既有手机视口及各用例设置的桌面／320px 宽度。
- 额外矩阵：WebKit 的 iPhone 13 模拟、Chromium 的 Pixel 7 模拟，以及桌面 WebKit 的三项滚轮用例。247 项通过，记录于 [矩阵结果](evidence/mobile-20260930/mobile-results.json)。
- Safari 移动模拟不支持 `mouse.wheel`，三项滚轮用例在桌面 WebKit 上执行；原生双指注入使用 CDP，只在 Chromium 执行。这些不是 iPhone 真机双指验收。
- 本机 macOS Safari 通过界面操作验证了原生手动下拉、柴油保存和刷新、加油指引、油种复选框及文字点击。记录见 [原生 Safari 证据](evidence/mobile-20260930/native-safari.json)。
- 没有实体 iPhone、Android 或母语真人安全审查。此处 PASS 只覆盖列明环境。

## 发现与修复

1. 直接点击 Safari 复选框会把焦点送至页面背景，使菜单在原生选择前关闭。阻止 pointer 默认事件又会吞掉 Safari 触屏点击。最终保留原生事件，通过菜单内部指针状态阻止过早关闭，并恢复菜单内的键盘焦点；键盘离开、外部点击和 Escape 仍正常关闭。回归明确覆盖输入框、文字、说明区域、禁用控件、一次只切换一次，以及之后的 Escape。
2. 地图筛选说明在小屏幕遮挡地区标记的点击。说明容器现在允许点击穿透，实际筛选按钮仍可点击；福冈／佐贺重叠汇总用例通过。
3. 图标原先吞掉第二根手指的触摸开始事件，导致落在图标上的双指无法缩放；保留单指点击处理，允许多指事件交给地图。
4. 列表自动滚入视口时的滚动事件误取消了当前悬停预览；现在只在指针确实离开待预览卡片时取消。
5. Safari 默认 Tab 不访问所有链接，指引链接测试按 [Apple 快捷键文档](https://support.apple.com/en-lamr/guide/safari/cpsh003/mac) 使用 Option/Alt+Tab，未修改用户 Safari 设置，也未放宽焦点断言。

## 证据区分

初次额外矩阵为 240 通过、5 失败，其中三项为移动 WebKit 的滚轮工具限制，两项为触屏选择与遮挡问题，见 `initial-mobile-results.json`。失败证据保留；不能把最初结果改写为全部通过。

修复后矩阵 247 项通过。随后补充“点击后键盘焦点仍在菜单”的回归，先重现 Safari 两项失败，再修复并重新运行最终全套及定向跨浏览器检查。最终定向20项通过，见 [跨浏览器油种日志](evidence/mobile-20260930/final-keyboard-fuel-check.txt)；失败日志见 [焦点回归失败记录](evidence/mobile-20260930/keyboard-focus-red.txt)。除菜单焦点实现和对应断言外，额外矩阵通过后的应用模块没有其他修改。

底图和外部导航在自动化检查中被拦截，不把合成底图截图当作地图服务在线证明；真实生产页面另行核验。测试期间产生的历史报告截图已恢复，保留原阶段证据。

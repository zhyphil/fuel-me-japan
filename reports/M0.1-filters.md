# Gas Now 式筛选功能完成报告

日期：2026-09-30。结论：**当前数据支持范围内的本地筛选功能通过验收**。本次来自用户明确要求提供参考截图的筛选功能；用户随后明确选择“暂时隐藏，只显示有数据支持的选项”。

## 已完成

| 功能 | 当前实现 |
| --- | --- |
| 筛选入口 | 地图左下与列表均提供漏斗按钮，显示已应用条件数量 |
| 品牌 | 当前已加载地区的品牌、标志或默认加油机图标、品牌搜索、多选、记录数；已确认别名合并 |
| 支付 | Visa、Mastercard，多选只匹配明确接受的记录 |
| 服务 | 自助加油、人工服务；保留日文“セルフ”标签 |
| 交互 | 三个图标页签、圆形选项与勾选标记、草稿结果数量、重置、应用、取消与 Escape |
| 结果联动 | 同类任一条件即可，不同类别同时满足，再与站点文字搜索取交集；地图与列表一致 |
| 状态 | 应用后关闭旧详情及聚合成员、列表回到前25条；切区／概览／新定位清除条件；仅重试不主动清除筛选 |
| 无障碍与语言 | 原生模态弹窗、键盘页签、焦点返回、英文／繁中／韩文／简中／泰文 |

现金、非接触支付、车队卡、洗车、厕所、充气等缺少资料的选项已隐藏，界面没有禁用占位。本项目仅有日本数据，未添加截图中的国家切换；车辆档案、付费、通知等其他功能不属于本次范围。

品牌筛选面板保留名称便于选择；地图水滴继续只显示品牌图标，无标志使用默认加油机。未知价格仍不显示，油种偏好和价格比较基准保持现有行为。

## 数据边界

全国当前16,454条站点，品牌已记录10,652条；自助875、人工65、服务未知15,514。Visa明确接受4条，Mastercard明确接受7条，接受任一卡的唯一站点共7条，不能相加成11条。东京818条记录的两类银行卡信息均未知。

支付筛选只匹配YES。界面保留现有字段对应的Visa／Mastercard，即使当前地区记录数为0；这与没有字段的选项隐藏不同。未匹配不代表不接受该支付方式。筛选只使用已加载站点，不新增全国下载、定位请求或筛选持久化。

实页核对：东京818条，ENEOS为391条，再与自助加油组合后18条，地图数量同步变化。截图见证据目录。

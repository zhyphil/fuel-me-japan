# 页头持续置顶（2026-10-01）

## 用户要求与修改

用户希望在手机向下浏览时仍能看到网站 Logo，并随时切换语言或业务页面。原页头随文档一起滚动，长页面底部无法直接使用这些入口；320px 基线检查中页头已移到视口外（y = -1600），测试失败。

- 统一页头持续置顶，保留 Logo、当前语言文字与地球图标，以及搜索加油站、还车加油、加油指引、关于四项导航。
- 根据页头真实高度给正文留出空间；五语言换行、窄屏和横竖屏切换时自动重新测量。地图首页继续使用原有视口高度与列表独立滚动。
- 语言菜单限制在可视高度内，必要时内部滚动；打开菜单不拉动原网页。页内定位和桌面还车地图同时预留页头空间。
- 预渲染页面在 JavaScript 尚未加载或禁用时仍采用正常文档中的吸顶页头；交互启动后用实测高度固定。手机站点详情继续使用原有独立浮层。

本次没有新增功能、改动数据来源或搜索收录设置。

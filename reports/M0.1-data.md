## 初始快照验证

- 共导出 22,098 条加油站几何表示；移除闭合路径的 5,644 条重复表示后，得到 **16,454 个带类型的 OSM 对象**：10,760 个节点、5,652 条路径、42 个关系。
- 完整的 OSM 都道府县边界恰为 47 个；每个站点只分配一次，无未匹配或归属不明确的记录。独立几何扫描与每个都道府县的输出数量一致。本次来源中未发现无效的站点或都道府县几何。
- 这只是 OSM 的部分覆盖，不代表站点清单完整，也不代表已按现实中的经营实体完成去重。坐标可能是区域的代表点，不一定是入口。
- 转换版本 `m01-data-v2`：服务类型为自助（`SELF`）的有 875 条，全服务（`FULL`）65 条，未知（`UNKNOWN`）15,514 条。缺失或带条件的燃油、支付、服务信息保持未知；不推断外国银行卡是否可用，不猜测车型燃油，不提供站点价格。
- 官方输出恰为 **141 条参考价记录**。主代理已将全部 47 × 3 项价格及调查 / 发布日期与原始工作簿独立比对。未使用区域汇总、上周列或煤油数据。参考价口径：现金、含税、日元 / 升（JPY/L）。
- 清单中的每项产物均通过 SHA-256 和字节数校验；分区、来源、价格结构及跨来源一致性也是每次构建的必检项。

## 已实现的检查

导入器的 16 项 Python 测试全部通过，覆盖几何与按对象类型去重、`UNKNOWN`、混合 / 条件属性、数量门槛、官方表格的覆盖范围 / 表头 / 单位 / 日期 / 数值、来源哈希、HTTP 403、解析失败，以及模拟最终指针切换失败。回归用例均先观察到失败，再在修复后通过。现有 TypeScript 数据测试覆盖全部实际分区、哈希、唯一性、运行时结构校验、相邻地区查找、Haversine 距离排序，以及损坏或中止的请求。应用和浏览器测试的最终汇总数量见 [完成报告](M0.1-completion.md)。

## 更新状态与限制

已实现离线导入、自动发现与检查命令，以及每周 OSM / 官方价格发布日候选数据工作流。这些命令不会推送代码或部署生产环境。工作流仍在本地，尚未在 GitHub 执行；须经审核并发布到默认分支后才能启用。候选产物需经过审核后才能发布。

当前环境向官方服务器发送 HTTP 请求时返回 403。官方浏览器下载成功，因此初始来源真实且可解析；**无人值守获取官方参考价尚未验证，在此环境仍受阻塞**。没有替换来源，也没有使用抓取绕过方案。来源获取失败时，保留最近一次已发布且验证有效的快照；界面仍显示调查日期和时效提示。

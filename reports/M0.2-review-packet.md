**接入决定：**两个样本仅保存在报告证据中。现有 `modelYearFrom/modelYearTo` 不可拿来装生产月份；本轮没有把目录年份硬填成年款，也没有预先扩大车型数据格式。应先取得可用来源与实际识别方式，再按最小必要范围调整匹配逻辑。

## 2. 允许使用评估

- [官方 WEB 目录的使用条件](https://toyota.jp/request/webcatalog/#conditional)限制未经许可复制、修改或分发目录的全部或部分；也提示目录可能不是最新版。
- Yaris 手册目录实际引用的 [条款加载脚本](https://manual.toyota.jp/pages/contents/ownersmanual/js/om_terms.js)加载[日文使用条件](https://manual.toyota.jp/common/lang/ja-jp/partial_terms.html)。正文对手册有同类限制，并提示版本可能与使用者车辆不符。网页提取工具没有显示这段动态内容，本轮以系统网络工具读取原文件核对，未执行下载脚本。
- [图片使用 FAQ](https://toyota.jp/faq/show/2216.html)讨论的是图片转载，不能单独用于判定所有车辆事实的使用方式。

拟用范围已经明确：人工核对少量日本市场车型的型号、配置、适用范围与油种，用自有文字／枚举整理，服务赴日自驾游客；作为商业网站的静态 JSON，并可能随公开 GitHub 仓库分发；附来源、范围和核查日期。拟使用内容不包括图片、表格截图、整段手册或 PDF 再发布。

本次没有取得足以批准上述具体用法的依据，所以保持 `PENDING_REVIEW`。这不是“所有车辆事实都不能商用”的法律结论，也不能靠模型或用户单独点头改变来源方的使用条件。

[中日双语咨询稿](M0.2-toyota-inquiry.md)已写好，明确询问结构化记录的商用、静态文件／公开仓库分发、许可流程及精确车辆识别依据。**尚未发送。**官方咨询首页是沟通入口，不代表已经找到授权受理部门；来信需先确认合适窗口。

原始 PDF、渲染图和网页仅用于临时目录核查，不纳入仓库或站点发布目录。本轮证据保存 URL、文件指纹、定位与中文评估，见 [review-packet.json](evidence/m02/source-review-20260930/review-packet.json)。

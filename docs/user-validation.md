# 外国自驾游客试用计划

准备日期：2026-10-01。**材料已准备；尚未招募或测试游客。** 本计划核对真实游客能否完成找站、手动选油、理解指引和还车准备。负责人已经确认的三个 iPhone Chrome 操作，不计入游客样本。

## 首批对象和安排

- 目标10位非项目成员、计划赴日或正在日本自驾的外国游客。首批地区计划为北海道3位、冲绳3位、九州七县4位；这是招募配额，不是已完成样本。
- 尽量覆盖五种界面语言，每种至少2位；地区与语言的完整交叉覆盖不在这10位内保证。无法找到某语言使用者时，明确记录缺口。
- 每位约15分钟，使用自己的手机。只在停车且未操作车辆、未加油时测试。不要求定位、真实驾驶、支付或提交租车合同。
- 使用正式网站；开始时记录页面发布版本、界面语言、手机／浏览器和 Wi-Fi／移动网络。设备／网络用于复现问题，不记录精确位置、姓名、邮箱或预约号码。
- 先说明记录用途，并征得参与者同意。参与者可随时停止；无需录音录像。拒绝记录的反馈只用于当场讨论，不写入结果表。
- 英文招募与任务单见 [参与者材料](user-validation-participant.en.md)，尚未发送，也未经母语真人审核。它不替代五语言安全文案审核。

## 不提示操作方法的四个任务

| 编号 | 主持人给出的目标 | 完成标准 | 观察重点 |
| --- | --- | --- | --- |
| A 找站 | 手动选择计划旅行的地区，找一间加油站，打开详情，并说明下一步如何导航。可以拒绝定位。 | 自行找到详情和导航入口；能说出资料没有保证营业、油种或单站价格。无需真的启动导航。 | 是否误把地区参考价当单站报价；列表、小地图和筛选是否有帮助。 |
| B 手动选油 | 使用虚构情景：“你的租车文件明确写着柴油／軽油”。设置默认显示油种，刷新，再改为两种油。 | 手动设置柴油，刷新保留；能选两种，且理解设置不是车辆自动核验。 | 复选框文字点击、日文标签、默认设置与多选是否容易理解。 |
| C 理解指引 | 找到加油指引，解释レギュラー、ハイオク、軽油，以及加油前应确认什么。 | 能区分三种燃油，并说明以租车文件和油箱盖为准；能找到停车熄火、禁烟等安全说明。 | 对柴油／汽油混淆等安全误解逐项记录，不能由主持人补答案后记为独立成功。 |
| D 还车准备 | 使用虚构预约门店：北海道为Toyota新千岁Poplar；冲绳为Toyota那霸Seaside；九州为Toyota福冈INTERNATIONAL。找到门店和附近一站，说明先后顺序。 | 找对门店、区分设施与柜台，选择候选；说明先加油、完成后返店，且地图点不是已核实入口、直线距离不是开车时长。 | 搜索、分页、地图联动、实际地址和未知油种提示是否帮助决策。无需实际导航。 |

每个任务先给3分钟独立尝试。超过3分钟仍可继续讨论，但记为未独立完成。遇到页面故障记录失败并保留，不从分母中删除；参与者主动停止、题目不适用则单独记为未测。主持人给提示后完成记为 `ASSISTED`，不可改记为 `SUCCESS`。切换语言后再重复属于复测，另列记录，不覆盖首次结果。

## 记录与判断

[结果表模板](user-validation-results.csv)只有表头，没有虚构测试结果。字段值规则：

- `participant_id`：随机匿名代号；`region`：`hokkaido`／`okinawa`／`kyushu`；`locale`：现有五种locale；`task_id`：`A`／`B`／`C`／`D`。
- `attempt`：首次为1，复测递增；`outcome`：`SUCCESS`／`ASSISTED`／`FAIL`／`NOT_TESTED`；`duration_seconds`：从给题到结束的观察秒数，无记录留空。
- `failure_category`：`NONE`／`DISCOVERY`／`LAYOUT`／`DATA_MISSING`／`LANGUAGE`／`MISUNDERSTANDING`／`NETWORK`／`OTHER`；`safety_misunderstanding`：`YES`／`NO`／`NOT_ASSESSED`；`help_requested`：`YES`／`NO`。
- `consent_to_record`：只写 `YES` 的参与者；`notes` 只写问题现象，不写姓名、精确位置、车牌、预约信息或合同照片。

填好的表放在仓库之外的私人目录，不提交Git；公开报告只使用匿名汇总和脱敏现象。原始记录在完成本轮汇总与复测后30天内删除；可识别信息不应在收集时进入表中。

每项独立完成率＝首次 `SUCCESS` 数／首次实际尝试数（包含 `ASSISTED` 与 `FAIL`）；未测和复测分别列出。首批自定门槛为每项至少8／10独立完成、没有未解决的安全误解；这是产品试用规则，**不是行业基准，也不是付费需求或市场验证**。不足10位时只汇报人数与问题，不宣称通过该门槛。

优先修复会混淆燃油、把柜台当还车点或把地图点当车辆入口的问题；再处理阻断任务的布局、搜索和数据缺口。普通偏好记录下来，不据此自动增加新功能。给每项问题记录复现路径、影响任务和下一次复测标准。

五语言母语审查单独记录：由熟悉加油场景的相应语言使用者检查三种燃油、安全提醒、未知数据、柜台／设施／入口、直线距离和加油→返店顺序。游客会操作、AI审查和自动化测试都不能替代这项审核。

## 与最初目标的关系

原始 [07验证规格](../Fuel-Me-Japan-M0-Handoff-Package/07-ANALYTICS-VALIDATION.md)要求约500名相关真实访客，至少25%启动核心任务、至少15%的详情使用者点击导航或gogo；这些是事先设定的实验规则。10位主持人陪同试用只能发现使用障碍，不能证明500人实验或自然转化达标。

当前事件接口仍为 no-op，没有访客数量、重复使用或转化数据；本轮不启用分析、Cookie或位置收集。gogo付费方向暂缓，不能把不存在的入口记为转化。后续大样本验证需先确定实际获客渠道和获准使用的最少统计方案；不得从自己的测试点击、爬虫或GSC发现页面数推导真实用户需求。

# 数据字段缺口与机场核对队列

统计日期：2026-10-01。当前基线见 [完整JSON](../reports/evidence/next-stage-data-maintenance-20261001/data-quality.json)，原准备阶段证据保留在 [历史JSON](../reports/evidence/validation-foundation-20261001/data-quality.json)。这是已加载快照的字段统计，**不是日本实际门店覆盖率、实时营业或可用油种保证**。

## 可重复的离线统计

```sh
npm run data:quality -- --as-of 2026-10-01 --output /tmp/fmj-quality.json
```

只读取本地 `public/data`，不下载来源、不请求定位、不写生产数据、不发送分析。它逐一核对110个已引用资料的字节数和SHA-256，用现有严格解析器检查来源、版本、枚举、分区计数和跨分区重复ID，再统计字段。报告输出禁止放入 `public/`；统计日期不可早于输入资料日期。相同输入及统计日期应生成相同报告，统计日期不改变资料刷新日期。

全国基线：16,454个加油站；7,383条租车记录，其中32条柜台、默认目录7,351条，19家设施有官方有限事实。地图车辆入口全部未核实。都道府县参考价141条，调查日期2026-09-28、公布日期2026-09-30；单站报价0条。

## 首批机场样本

队列覆盖新千岁、那霸、福冈8家现有官方设施。每家选取按10公里直线距离排序的前三个普通汽油候选，去重后17个站点。算法复用现有候选逻辑：仅排除所选油种明确NO的记录，UNKNOWN保留。这是人工核对抽样，**不是加油或行车路线推荐**。

JSON保留门店ID、来源页、原核对日期、站点OSM ID／公开位置／记录链接、逐字段缺口和对象最后修改时间。OSM最后修改时间不能当作现场核验时间；本次读官网也不会自动刷新生产门店的核对日期。

核对顺序：先用确切地址、门店专属URL／电话或稳定源ID确认同一业务；再查地址、营业时间及所有季节／休业例外、服务方式、明确油种和支付信息。普通官网品牌、搜索摘要、相邻位置、旧照片不足以确认某站事实。找不到相应依据时保留UNKNOWN，不补造。

官方资料只有在允许使用的有限事实范围、身份明确且证据充分时才能进入相应数据契约。不能把核对表直接当成OSM批量编辑，也不能覆盖原始来源。新增生产字段或来源需先完成来源登记、共用契约／输入锁与五语言文案检查，再运行数据和应用验收后发布。

## 候选更新差异

```sh
npm run data:quality -- --output /tmp/after.json --compare /tmp/before.json --changes-output /tmp/changes.json
```

差异报告包含全国／三地区数值变化、manifest变动、日期倒退及手工补充停用提示。兼容没有 `displayedStations` 的旧schema-1基线。`REVIEW_REQUIRED`需要人工审核；`UNCHANGED`仅表示已验证候选与基线没有这些变化，不等于来源请求成功。两项比较参数必须一起提供，输出仍禁止放在公开数据目录。

现有只读刷新工作流在获取前保存质量基线，在成功或保旧失败后生成差异；与精确HTTP失败诊断一同保留14天，不自动提交或部署。维护步骤见[维护手册](data-maintenance.md)。当前无需游客试用计划或记录模板才能继续上述维护。

# Fuel Me Japan

面向赴日自驾游客的多语言加油站地图和还车前加油工具。正式网站：[fuel-me-japan.com](https://fuel-me-japan.com/zh-Hans/)；联系邮箱：contact@fuel-me-japan.com。

当前线上应用`77c7e19`、Cloudflare生产部署`7669b265`。最新任务见 [TASKS.md](TASKS.md)，原始 [00–10交接规格](Fuel-Me-Japan-M0-Handoff-Package/10-CLAUDE-CODEX-HANDOFF.md)保持原样；后续用户范围调整以当前TASKS和AGENTS为准。

## 当前功能

- 找站地图与列表、品牌水滴、显式定位、数据支持的品牌／支付／服务筛选、最便宜／最近／收藏、逐站小地图、悬停联动和油种多选。无有效单站价格时不显示价格；价格排序不能把地区参考价当单站价。
- “我的用油”只提供普通汽油／高辛烷值汽油／柴油的手动下拉选择，在当前浏览器保存并联动地图；地图多选仍可使用。手动设置不是车辆用油核验，车型识别及厂家咨询暂缓。
- 独立“加油指引”页面提供五个短步骤、七个日文识别标签和安全提示，以租车文件与油箱盖为准。
- 独立“还车加油”目录有全国7,383条候选／柜台／设施记录，默认隐藏32条柜台，可按地区、公司、名称、地址或机场代码搜索；总地图与逐店小地图、限高列表及10／25／50／100分页，默认25，支持直接输入页码。
- 七个重点机场合计19家设施有官方有限事实，不代表全国候选都可还车。详情有附近10公里直线距离加油候选、分页、小地图与悬停联动地图；选站后先加油，明确完成后再显示返店导航。所有车辆入口仍未实测核实。
- 页头导航、Logo与当前语言入口置顶；五语言独立About、来源／限制、隐私说明与联系邮箱。界面为en、zh-Hant、ko、zh-Hans、th，保留日文油种和现场标签。

## 开发与检查

使用 `.nvmrc` 的Node24和锁定依赖：

```sh
npm ci
npx playwright install chromium
npm run dev
npm run check
```

`check`依次运行lint、TypeScript、单元测试、静态构建／预渲染和Chromium浏览器测试。外部导航、定位与瓦片在自动化中模拟，不读取开发者真实位置。额外WebKit／Android模拟与macOS Safari检查以各报告范围为准，不等同于实体手机验收。

用户已确认iPhone15ProMax Chrome的详情滑动、还车分页、Logo／语言置顶三项正常；其他操作、Safari、Android和五语言母语审查不能据此标为通过。见 [真机与Google跟进报告](reports/ads-consent-followup-20261001.md)。

```sh
npm run test:data
npm run data:quality -- --as-of 2026-10-01 --output /tmp/fmj-quality.json
```

质量工具离线核对110份引用资料，并统计当前快照字段缺口，不能修改生产数据或刷新来源日期。见 [数据缺口说明](docs/data-quality.md)、[维护手册](docs/data-maintenance.md)、[核心导入流程](docs/data-pipeline.md)和[租车数据契约](docs/rental-data.md)。

## 来源、隐私与公开状态

React＋TypeScript＋Vite静态网站；无后台、数据库、账号、支付、车型推荐、站内行车路线引擎或即时油价抓取。

- 加油站使用已审核OSM快照；选都道府县按需加载，拖图不自动下载邻省。租车库使用OSM＋Overture去重资料，仅进入还车业务时请求全国索引，再按需请求详情。
- OSM标准瓦片独立配置，会向外部服务发送浏览区域与普通网络信息；无预取／离线瓦片缓存，保留可见署名、许可和完整衍生资料下载。
- 显式点击才请求定位；精确位置不持久化、不进入分析事件。分析仍为no-op。外部导航只传送目的地，权限与路线由外部地图处理。
- 缺失字段保持UNKNOWN；营业时间保留季节／例外，不推断实时营业。19家官方设施有限事实与全部未核实车辆入口分别展示，不宣称公司整库授权。
- 都道府县参考价141条，调查2026-09-28、公布2026-09-30；当前单站报价为空。gogo.gs付费接入及商务跟进暂缓，不复制其私有报价材料或运行抓取。
- 五语言首页／目录／指引／About共20个主页面已开放搜索收录；详情、参数及部署别名保留相应限制。GSC清单已成功读取、发现20页，实际索引统计仍待处理，不能称20页已收录。
- 根路径ads.txt和用户指定AdSense验证代码已上线。AdSense仍审核中、后台ads.txt识别待更新；Google同意设置已发布，但实际窗口完整交互未通过验收。广告请求保持暂停，不宣称广告已投放。
